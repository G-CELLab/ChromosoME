# Tutorial Knowledge

## Scope
- This file is tutorial-only.
- It covers pre-cell onboarding tasks before mitosis learning phases.
- Phase-specific in-cell flow is in `scene_knowledge.md`.

## Tutorial Interaction Practice
- Practice goals in tutorial:
  - Touch and hold the sphere on the hand for about 3 seconds.
  - Grab highlighted objects and move them to targets.
  - Duplicate an object by pulling one copy away and holding it.
- Example guidance:
  - "What do I do first?" -> Touch and hold the sphere on your hand for a few seconds.
  - "How do I grab it?" -> Reach out and use the grab control to pick it up.
  - "How do I duplicate it?" -> Move one copy away and hold it there briefly.

## Tutorial Object References (Color/Shape/Location)
- Chromosome: blue X-shaped object in the middle.
- Chromatid: red object on the right.
- Centriole: small yellow barrel-shaped object on the left.

## Tutorial Question-Type Coaching
- Content questions:
  - Focus on definitions/functions of biology terms.
  - Example: "What is a chromosome?" and "What does a chromosome do?"
- Visual reference questions:
  - Connect terms to visible objects in scene.
  - Example: identify chromosome as the blue X-shaped object in the middle.
- Manipulation questions:
  - Ask how to move/interact with objects.
  - Example procedure: make the grab gesture and place the object in the highlighted area.

## Tutorial Finish
- At tutorial completion, prompt learner to touch and hold the glowing yellow spot in front of them to enter the cell.
